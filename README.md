# Beltanee · ТСД Studio

Интерактивная демонстрация приложения FBS для терминала сбора данных.

## Сайт

https://golunovoleg111-rgb.github.io/TSD-STUDIO/

Сборка, приёмка, поиск ячеек, ручной ввод, журнал действий и сценарии ошибок. Кнопка «Режим показа» упрощает экран для демонстрации.

Все данные примерные. Рабочий сайт не подключён. Печать не выполняется.

Статический сайт без установки зависимостей. Для локального запуска можно использовать любой HTTP-сервер.
